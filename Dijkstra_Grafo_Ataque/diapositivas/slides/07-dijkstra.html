🔴 Dijkstra: la ruta crítica

Implementación propia · heap binario

def dijkstra(G, src, dst):
  dist = {v: ∞ for v in G}
  dist[src] = 0
  pq = MinHeap([(0, src)])     # O(log V)
  while pq:
    d, u = pq.pop_min()
    if u == dst: break
    for v, w in G[u]:
      # relajación
      if d + w < dist[v]:
        dist[v] = d + w
        prev[v] = u
        pq.push((dist[v], v))
  return rebuild(prev, dst)
Complejidad: O((V+E)·log V) con heap binario.
