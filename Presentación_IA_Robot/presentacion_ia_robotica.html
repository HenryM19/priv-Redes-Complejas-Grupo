¿Qué es un Agente de IA?

Un agente de IA es un sistema autónomo que percibe su entorno, toma decisiones y actúa para alcanzar objetivos específicos.

PERCEPCIÓN ↓ [AGENTE INTELIGENTE] ↓ ACCIÓN → Impacto en el mundo

En robótica:

  • 📡 Percepción: Sensores (cámaras, encoders, IMU)
  • 🧠 Inteligencia: Red neuronal que decide los movimientos
  • ⚙️ Acción: Motores mueven el brazo robótico

Agentes Conectados: MCP Servers

Un agente de IA puede conectarse a múltiples aplicaciones y servicios

🔧 GitHub API

Crear repos, commits, PRs automáticamente

📊 Google Drive

Leer/escribir documentos, hojas de cálculo

⚙️ Blender API

Generar modelos 3D, URDF, simulaciones

✨ Caso práctico: Claude (agente IA) + MCP Blender → Diseñó automáticamente un brazo robótico 6-DOF desde descripciones textuales

📝 Comentario: La Magia del Prompt

Entrada simple:
"Crea un brazo robótico industrial con 6 articulaciones, gripper paralelo de 2 dedos, base fija en z=0"

Claude interpreta esto como:

  • ✅ 6 eslabones (links) + 6 articulaciones (joints)
  • ✅ Proporciones realistas de un robot industrial (ej. FANUC)
  • ✅ Parámetros dinámicos: masas, fricción, límites de movimiento
  • ✅ Formato exportable: URDF compatible con ROS 2

Resultado: Sin escribir código, tenemos un modelo parametrizado y validado.

  • 1 brazo, 1 experimento a la vez

✅ Simulación GPU

  • 64+ brazos en paralelo
  • Sin riesgo

El Problema Clásico: Programar un Brazo Robótico

Enfoque Tradicional (IK)

  • Ecuaciones matemáticas explícitas
  • Requiere calibración perfecta
  • Falla ante perturbaciones
  • Un experto por robot/tarea

¿Qué Queremos?

  • Sistema que aprende como humanos
  • Robusto a incertidumbre
  • Generalizable a nuevas tareas
  • Sin programación manual

💡 Pregunta Clave: ¿Puede una red neuronal aprender cinemática inversa solo por experiencia, sin que nadie le enseñe las ecuaciones?

La Solución: Aprendizaje por Refuerzo en Simulación

AGENTE (Red Neuronal) │ acción │ (ángulos de joints) ▼ ┌─────────────────┐ │ SIMULADOR │ recompensa │ FÍSICO (GPU) │ (+ si acierta) │ 64 brazos // │ ──────────────▶️ AGENTE └─────────────────┘ 1 iteración = 64 brazos × 30 pasos = 1920 experiencias

Infraestructura Computacional Requerida

GPU Recomendada

  • Básico: RTX 3090 (24 GB) → 64 entornos
  • Medio: RTX 4090 (24 GB) → 256 entornos
  • HPC: A100 (80 GB) → 2048+ entornos
  • Clúster: 8× H100 (640 GB) → 16k+ entornos

Software Base

  • Ubuntu 22.04 + CUDA 12.x
  • Docker + NVIDIA Container Toolkit
  • Isaac Sim 5.1 (contenedor oficial)
  • Isaac Lab 2.3

CPU vs GPU: CPU (16 cores) = 30 pasos/seg | GPU RTX 4090 = 57,600 pasos/seg = 190× más rápido
