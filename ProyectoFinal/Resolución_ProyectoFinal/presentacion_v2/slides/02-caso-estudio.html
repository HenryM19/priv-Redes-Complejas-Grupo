El escenario

Un grafo simple, no dirigido y conexo

La red se reconstruyó a partir de 34 diagramas técnicos del informe "Diagramas de red final". El resultado es un grafo simple, no dirigido y conexo, organizado en una topología estrella jerárquica de tres capas: core → agregación → acceso, con seis campus y dos sedes interconectados por una nube MPLS de proveedor externo.
